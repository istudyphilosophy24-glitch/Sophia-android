# SOPHIA 9.0 — The Definitive Academy

This is the final numbered edition of the native Android philosophy learning application.

## Content and measurement

- 30 courses, 300 units, 1,800 concepts, 3,600 lesson paths
- 420 annotated excerpts in the Great Library
- 20 original short thematic seminar scripts
- 330 course lectures (30 introductions and 300 guided unit lectures)
- Historical-source seminar listening sessions assembled from 13 historic Project Gutenberg editions archived in SOPHIA 5.0.

The program data is generated by GitHub Actions from the earlier SOPHIA 5.0 APK artifact and word counts are measured. The release must exceed 100 hours at a brisk 150 words/minute. Most of that time is narrated historical primary texts with introductions and reflection prompts; a smaller share is SOPHIA-authored teaching, not 100 hours of original professorial lectures. There are no prerecorded MP3s, only audio-ready text read using Android TTS.

The on-demand ZIP catalog allows long episodes without loading all of the text on the main screen. Features include search, chapters, favorites, saved position, Android background playback, media controls, voice selection, and a sleep timer.

## Academic integrity

Source texts are credited to named Project Gutenberg editions and historic translators. Their US public-domain classification does not ensure rights in every country; the Gutenberg license is included. The Great Library itself keeps excerpts rather than full works. Editorial commentary is instructional rather than externally peer-reviewed.

## Building

GitHub Actions retrieves the historical-source APK artifact from SOPHIA 5, generates the audio catalog, validates the 100-hour floor and curriculum, then compiles with JDK 17, Android SDK 35, Gradle 8.10.2 and Kotlin 2.1.20.

Package ID: com.sophia.philosophy.definitive9. Android 7.0+. Previous installations coexist; progress is not automatically migrated. Backups can be exported and compatible SOPHIA-native data imported in Scholar Settings.

No mini-games or standalone Argument Architect. Future work should be verified content packs, accessibility, security patches, and fixes rather than new major version numbers.
